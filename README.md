# A Little Note for You

A small, responsive love letter website built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. There is no build step, package installation, or environment variable required.

## Deploy to Vercel

1. Import this repository in [Vercel](https://vercel.com/new).
2. Keep the Framework Preset as **Other** if Vercel asks.
3. Leave the Build Command and Output Directory empty. The site is a static HTML page.
4. Deploy.

Vercel will serve `index.html` from the project root.

## Customize

Edit the text in `index.html` to personalize the letter. The styling and interactive surprise message are included in the same file.
